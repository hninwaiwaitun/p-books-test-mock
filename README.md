# 🔧 P社管理画面改修プロジェクト：環境構築手順 兼 完了報告書

本プロジェクトの開発を始めるための環境構築手順です。
各手順が完了したら、`[ ]` を `[x]` に書き換えて（チェックを入れて）保存してください。

## 🚀 構築手順チェックリスト

### ⬜ STEP 1: 依存ライブラリのインストール
- [x] 1-1. 配布された `SampleApp` フォルダを VS Code で開いた。
- [x] 1-2. VS Code の上部メニュー「ターミナル」＞「新しいターミナル」を開いた。
- [x] 1-3. 以下のコマンドをコピーしてターミナルに貼り付け、Enterを押し、必要なライブラリを一括インストールした。
```bash
  npm install

```

### ⬜ STEP 2: Vue 3 / SCSS を動かすためのプラグイン導入

* [x] 2-1. 以下のコマンドを実行し、Vueファイルを翻訳するプラグインを導入した。
```bash
npm install @vitejs/plugin-vue -D

```

* [x] 2-2. 以下のコマンドを実行し、SCSS（Sass）をコンパイルするエンジンを導入した。
```bash
npm install sass -D

```

### ⬜ STEP 3: 開発サーバーの起動確認

* [x] 3-1. 以下のコマンドを実行し、ローカル開発サーバーを起動した。
```bash
npm run dev

```
* [x] 3-2. ターミナルに表示された URL（基本は http://localhost:5173/ ）をブラウザで開き、ログイン画面が表示されることを確認した。

### ⬜ STEP 4: VS Code 拡張機能の導入（GUI操作）

* [x] 4-1. 拡張機能「Vue - Official」を検索してインストールした。
* [x] 4-2. 拡張機能「Sass」を検索してインストールした。
